================================================================================
                 CONNEXION — PATIENT
================================================================================

Le patient consulte dans un seul compte les résultats (laboratoire, imagerie,
exploration fonctionnelle) et les factures de tous les établissements où son
dossier est rattaché. Chaque résultat indique son établissement.

Espace : https://rohafya.com/patients

Rôle : Patient. Il est donné automatiquement à la création du compte, avec ses
permissions (famille patients.*) ; rien à faire pour le patient.


1. QUELLE SITUATION EST LA VÔTRE ?
----------------------------------
  A. Vous avez reçu un QR code (ou un code court) sur une facture
     -> section 2 : c'est le chemin le plus simple, il crée le compte au besoin.
  B. Vous êtes déjà patient de PDMD Santé avec un identifiant et un mot de passe
     -> section 3.
  C. Vous voulez simplement vous connecter avec votre e-mail
     -> section 4.


2. PREMIÈRE CONNEXION PAR LE QR CODE DE LA FACTURE
--------------------------------------------------
  1. Scanner le QR code avec l'appareil photo du téléphone. La page
     « Rattacher mon dossier » s'ouvre et affiche le nom de l'établissement.
  2. Saisir son adresse e-mail, « Recevoir un code ».
  3. Saisir le code à 6 chiffres reçu par e-mail (valable 10 minutes),
     « Se connecter ».
  4. Si aucun compte n'existe pour cette adresse : saisir prénom et nom,
     « Créer mon compte ».
  5. Cliquer sur « Rattacher ce dossier à mon compte ».
       « C'est fait ! »       le dossier est rattaché, les résultats arrivent.
       « Demande envoyée »    l'établissement doit confirmer (l'e-mail saisi
                              n'est pas celui qu'il connaît) ; les résultats
                              apparaîtront après sa validation.
  6. « Voir mes établissements ».

  Lors de la toute première connexion, ROHAFYA ouvre d'abord la page « Paramètres » :
  compléter et enregistrer ses informations (nom, prénom, date de naissance,
  genre, lieu de naissance, nationalité, CNI, téléphones, e-mail). Les autres
  pages se débloquent ensuite.

  Le QR code ne sert qu'une fois. Pour un deuxième établissement, scanner
  simplement le QR code de sa facture : il s'ajoute au MÊME compte.


3. PATIENT HISTORIQUE (IDENTIFIANT ET MOT DE PASSE)
---------------------------------------------------
Les patients de PDMD Santé gardent leur accès habituel :
  1. https://rohafya.com/connexion, onglet « Mot de passe ».
  2. Cliquer sur « Patient », saisir identifiant et mot de passe,
     « Se connecter ».
  Identifiant oublié : « Mot de passe oublié? », saisir son matricule ; un
  nouvel identifiant et un nouveau mot de passe sont envoyés par e-mail.

Leurs résultats PDMD Santé restent visibles sans aucun QR code. Ils peuvent
aussi utiliser la connexion par code (section 4) si l'e-mail de leur profil
n'est utilisé par aucun autre compte.


4. SE CONNECTER AVEC SON E-MAIL (SANS MOT DE PASSE)
---------------------------------------------------
  1. https://rohafya.com/connexion, onglet « Code par e-mail ».
  2. Adresse e-mail > « Recevoir un code » > code à 6 chiffres > « Se connecter ».
  3. Sans compte existant : prénom, nom > « Créer mon compte ». Le compte est
     vide tant qu'aucun établissement n'y est rattaché (voir section 5).


5. GÉRER SES ÉTABLISSEMENTS
---------------------------
Menu « Mes établissements » :
  - liste des établissements rattachés (état « Rattaché » ou « En attente ») ;
  - « Ajouter un établissement » : saisir le code court imprimé sous le QR code
    (ex. K7P-4QX, tirets et espaces facultatifs), « Rattacher » ;
  - « Retirer » : les résultats et factures de cet établissement disparaissent
    du compte (rien n'est supprimé chez l'établissement ; un nouveau QR code
    permet de le rattacher à nouveau).


5 bis. ENVOYER UNE PRESCRIPTION, UN PRÉ-ENREGISTREMENT OU UNE REQUÊTE
--------------------------------------------------------------------
Ces trois envois sont adressés à UN établissement, choisi dans la liste de tous
les établissements actifs de ROHAFYA (pas seulement ceux où l'on est rattaché).
  Prescriptions         « Nouvelle prescription » : établissement, médecin
                        prescripteur, consignes, photo de l'ordonnance ; cocher
                        « Soumettre une demande de devis » pour connaître le prix.
  Pré-enregistrements   « Nouveau pré-enregistrement » : établissement, nom et
                        prénom (soi-même ou un proche), photo d'un document
                        (CNI, carte d'assurance…), obligatoire.
  Requêtes              « Nouvelle requête » : établissement, message,
                        catégories (prix d'un examen, examen externe, erreur…).

Suivi : chaque envoi affiche son établissement et son statut (Reçue, En cours,
Traitée, Refusée). Quand l'établissement répond, sa réponse s'affiche sous
l'envoi (« Réponse de l'établissement ») et le patient reçoit une notification
et un e-mail. Pour une demande de devis, « Voir le devis » montre le montant en
FCFA dès que l'établissement l'a fixé.

Sans compte : la page publique https://rohafya.com/requests permet d'écrire à un
établissement ; l'adresse e-mail est obligatoire, la réponse y est envoyée.
